# v0.9.7 Autonomous Recovery Supervisor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden and verify autonomous Windows recovery so RWMCP restores MCP/tunnel operation without SSH or manual intervention.

**Architecture:** Keep Control Center as the independent local recovery authority. Persist owner intent in `desired-state.json`, evaluate runtime/tunnel health in a separate recovery worker, and gate recovery during planned maintenance.

**Tech Stack:** PowerShell 5.1, Node.js 24, TypeScript, GitHub Actions Windows runner.

**Spec:** `docs/superpowers/specs/2026-09-17-v0.9.7-autonomous-recovery-design.md`

## Global Constraints
- SSH is break-glass only and must not be required by acceptance.
- Explicit owner Stop must never be overridden by autonomous recovery.
- Recovery backoff is capped at 60 seconds.
- Existing v0.9.6 Control Center and update/restart contracts remain backward compatible.
