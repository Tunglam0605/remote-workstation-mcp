# v0.9.8 Recovery Supervisor Heartbeat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add liveness heartbeat supervision for the Windows autonomous recovery worker.

**Architecture:** The recovery worker writes an atomic heartbeat file each evaluation. The persistent Control Center host verifies freshness and recycles a hung worker using its existing watchdog backoff.

**Tech Stack:** PowerShell 5.1, Node.js 24, TypeScript, GitHub Actions Windows runner.

**Spec:** `docs/superpowers/specs/2026-09-17-v0.9.8-recovery-heartbeat-design.md`

## Global Constraints
- Preserve v0.9.7 desired-state and manual Stop behavior.
- Heartbeat state contains no secret values.
- Startup grace: 15 seconds.
- Heartbeat stale threshold: 30 seconds.
- SSH is excluded from acceptance.
